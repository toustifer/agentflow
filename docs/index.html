Core Invariants

Built for Long-Horizon Repository Evolution

📦

One-Task-One-Worktree

Every assigned task executes within an ephemeral, physically isolated Git worktree. Erroneous edits, broken migrations, and crashes are atomically pruned without polluting the root codebase.

⚡

Decoupled Dual-Engine

A deterministic Go FSM acts as the single source of truth and enforces strict role-based access control (RBAC), while a reactive Python Behavior Tree schedules Leader, Worker, and Reviewer lifecycles.

🧠

Off-Context Memory

Transcripts are externalized into SQLite. Worker Handbooks persist discrete domain pitfalls (e.g. library compatibility and ORM quirks), eliminating repeated errors while keeping active context under 2,000 tokens.
